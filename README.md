# Smart Bank Management System

A Python-based Bank Management System with a modern graphical user interface (GUI) built using Tkinter.

## Features

- Create a new bank account.
- Deposit money.
- Withdraw money.
- Check available account balance.
- Show or hide account balance.
- View transaction history.
- Filter transactions by type.
- Search transactions.
- Light and Dark mode.
- Interactive dashboard with financial summaries.
- Input validation and transaction confirmation.

## Technologies Used

- Python
- Tkinter
- ttk
- Math
- Random
- Datetime

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yashwant1448/Bank-System-Website.git
   ```

2. Open the project folder:

   ```bash
   cd Bank-System-Website
   ```

3. Run the application:

   ```bash
   python Bank.py
   ```
